Enter your Mux API credentials

Paste the Token ID and Secret Key from your Mux dashboard (Settings → Access Tokens). They are sent to this server only to be validated against the Mux API — this form never saves them to the website database, the browser or the source code.

Where the credentials are stored

Website code can read Base44 secrets but cannot write them, so the two values are stored in Base44, not in this database:

  1. Open Base44 → Secrets for this app.
  2. Add a secret named MUX_TOKEN_ID and paste the Token ID.
  3. Add a secret named MUX_TOKEN_SECRET and paste the Secret Key.
  4. Save. Base44 recreates the app with the secrets available, then come back here and press Re-check connection.

No webhooks are required: Mux processing status is read by polling from the server, so nothing has to be configured in the Mux dashboard.

Upload limits

No storage quota or video-count limit is applied by this application. Library growth is bounded only by your Mux plan (usage-based billing and Mux's own per-upload limits). Failed uploads are never published as playable videos and nothing is deleted automatically.
